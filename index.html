Auto-Post

Última atualização: 10 de Novembro de 2026

O Auto-Post é uma ferramenta CLI (Command Line Interface) proprietária, projetada para agendamento e publicação automatizada de conteúdo em redes sociais. Este site serve como repositório oficial para os nossos Termos de Serviço e Política de Privacidade.

1. Termos de Serviço

Ao utilizar o Auto-Post, você concorda com os seguintes termos:

  • Uso Pessoal: A ferramenta é fornecida "como está" (as-is), sem garantias de qualquer tipo. O usuário é o único responsável pelo conteúdo que publica e pelo cumprimento das diretrizes das plataformas de destino.
  • Responsabilidade: Não nos responsabilizamos por contas suspensas, banimentos ou perdas de dados decorrentes do uso da ferramenta.
  • Propriedade Intelectual: O código-fonte do Auto-Post é de propriedade exclusiva do autor e não é de código aberto. Este repositório do GitHub contém apenas as páginas legais exigidas para integração com as plataformas.

2. Política de Privacidade

A sua privacidade é importante. Esta política descreve como o Auto-Post lida com os seus dados:

  • Coleta de Dados: O Auto-Post não coleta, armazena ou transmite dados pessoais para servidores externos.
  • Tokens de Acesso: Quando você autoriza o app (via OAuth) a postar em seu nome, o token de acesso gerado pela plataforma (TikTok, YouTube, etc.) é armazenado exclusivamente na sua máquina local (na pasta ~/.config/autopost/).
  • Uso dos Tokens: Os tokens são usados apenas para fazer as requisições de publicação diretamente para as APIs oficiais das plataformas. O Auto-Post não tem acesso ao seu e-mail, senha ou dados privados da conta.
  • Compartilhamento: Nenhum dado é compartilhado com terceiros ou usado para fins de marketing.
